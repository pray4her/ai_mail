## What to build

新增受控草稿回复样式渲染底座，让自动生成的草稿回复在开启样式配置后保存为同时包含纯文本和 HTML 的草稿邮件，并在关闭样式配置时保持当前纯文本行为。

这一切应保持 AI 只生成纯文本正文，系统负责把草稿回复正文渲染成受控 HTML。第一版只覆盖基础正文样式，包括字体族、字号、正文颜色、链接颜色、背景色、容器背景色、行高、段落间距、最大宽度和内容内边距。

## Acceptance criteria

- [ ] `app.mail.auto-reply.style.enabled=false` 时，草稿回复继续保存为当前纯文本草稿行为。
- [ ] `app.mail.auto-reply.style.enabled=true` 时，草稿回复保存为 `multipart/alternative`，同时包含 `text/plain` 和 `text/html`。
- [ ] AI 生成内容仍按纯文本处理，不允许 AI HTML 作为最终邮件格式直接发送。
- [ ] HTML 正文渲染会对源文本做 HTML escape。
- [ ] 空行被渲染为段落，段落内单换行被渲染为 `<br>`。
- [ ] 基础样式配置通过 typed configuration 绑定到 `app.mail.auto-reply.style`。
- [ ] 非法基础样式配置在应用启动期失败，而不是运行时静默降级。
- [ ] 字体族只允许 `system`、`microsoft-yahei`、`serif`、`monospace`。
- [ ] 颜色配置只允许六位 HEX 值。
- [ ] 数值配置按计划文档中的范围校验。
- [ ] `MailSendService.saveDraftToFolder` 的公开签名保持不变。
- [ ] 数据库中的 `reply_content` 仍保存 AI 原始草稿回复正文，不保存渲染后的模板内容。
- [ ] 默认自动测试不依赖真实 IMAP。
- [ ] 新增测试覆盖配置校验、纯文本转 HTML、关闭样式回退和开启样式后的 MIME 行为。
