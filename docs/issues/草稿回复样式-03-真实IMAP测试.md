## What to build

新增显式启用的真实 IMAP 草稿回复样式 smoke/integration 测试，用于把样式化草稿回复保存到真实邮箱中的测试文件夹，方便人工打开邮箱客户端检查 HTML 草稿实际展示效果。

该测试不进入默认测试套件，必须通过环境变量显式开启。测试应以简单、可人工验证为优先，不自动清理生成的测试草稿。

## Acceptance criteria

- [ ] 默认 `mvn test` 不运行真实 IMAP smoke 测试。
- [ ] 真实 IMAP smoke 测试只能通过显式环境变量开启。
- [ ] 测试草稿保存到 `AI_reply_test` 或明确的测试专用文件夹。
- [ ] 测试主题包含 smoke 标记和时间戳，便于人工查找。
- [ ] 测试草稿包含 HTML 样式、plain text 兜底以及已启用的模板组件。
- [ ] 测试不自动删除草稿，方便人工打开邮箱客户端检查展示效果。
- [ ] 当缺少必需 IMAP 环境变量时，测试应跳过或给出清晰原因，而不是误报业务失败。
- [ ] 文档说明如何启用真实 IMAP smoke 测试、需要哪些环境变量、以及如何人工验证。
