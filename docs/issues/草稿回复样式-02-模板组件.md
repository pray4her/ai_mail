## What to build

在受控草稿回复样式渲染底座上新增第一版模板组件：安全普通链接、配置型 CTA 链接按钮、可选页眉、公司名、HTTPS Logo + alt、文本签名和页脚。

模板组件应保持单列邮件布局、table 结构和 inline CSS。所有组件均由后端配置控制，不允许 AI 生成结构化 CTA，不开放任意 HTML/CSS，也不支持 CID 图片。

## Acceptance criteria

- [ ] 正文中的 `http`、`https`、`mailto` URL 会自动渲染为普通链接。
- [ ] 裸域名如 `example.com`、`www.example.com` 不会自动链接化。
- [ ] URL 不会被改写，也不会追加追踪参数。
- [ ] 不安全协议如 `javascript:` 会作为普通文本处理，不生成链接。
- [ ] CTA 仅来自配置，支持 `http`、`https`、`mailto` URL。
- [ ] CTA label 长度限制为 1 到 40 个字符，URL 长度限制为最多 2048 个字符。
- [ ] CTA 使用 table + `<a>` 渲染，不使用真实 `<button>`。
- [ ] 页眉启用时必须配置公司名或启用 Logo。
- [ ] Logo 只支持 HTTPS URL，必须配置 alt，且受最大宽度限制。
- [ ] Logo 不使用 CID、不下载、不转存、不内嵌。
- [ ] 文本签名启用时必须配置非空文本。
- [ ] 页脚启用时必须配置非空文本。
- [ ] HTML 组件顺序为正文、CTA、文本签名、页脚。
- [ ] plain text 版本也追加 CTA、文本签名和页脚文本，保持双版本语义一致。
- [ ] header 和 Logo 不进入 plain text 版本。
- [ ] 新增测试覆盖安全链接、CTA、页眉、Logo、文本签名、页脚、plain text 追加规则和非法配置。
